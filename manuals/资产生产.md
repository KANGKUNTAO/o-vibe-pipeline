# 资产生产手册(M2)— 2D 资产生成 + 确定性质检

> 五步工作流第 4 步(资产精修)的展开。目标:把 manifest 里的占位资产逐件换成达标成品,**每件有出处、过评分、可追溯**。
> 行业难题背景:2D 生成的一致性(帧间/全局风格)未被工具解决 → 本管线的差异化就是把质检做成**确定性评分器**,不靠人眼。
> 状态:框架版(2026-09-29);评分器实现于 `tools/评分器/`,随 001 落地。

## 2D 资产分类与规格约定

| 类别 | 规格 | 格式 | 质检重点 |
|---|---|---|---|
| 立绘/精灵 spr | 2 的幂尺寸,透明底,中心锚点 | PNG | 剪影完整、调色板一致 |
| 动画帧 eff/spr | 帧数固定,同尺寸,同锚点 | PNG 序列 | **帧间一致性**(本手册核心) |
| tileset | 网格对齐(64/128),可平铺 | PNG | 平铺无缝、格线对齐 |
| UI | 九宫格切片标注,标准控件尺寸 | PNG | 可拉伸、文字区留白 |
| 音效/音乐 audio | 音效 ≤200KB,BGM 循环无缝 | MP3/OGG | 时长、采样率、响度 |
| 字体 font | 中文子集化 | TTF/BMFont | 覆盖游戏全部文案字符 |

具体数值在立项卡定,写进 manifest 的"规格"列,评分器按 manifest 检查。

## 每件资产的生产流程(状态机)

```
占位 → 生成中 → [评分器] 达标 → 已入库
                ↘ 不达标(重试 N 次)→ 需授权(换素材源)→ 已入库(记出处+许可证)
                ↘ 源也没有 → 缺口(如实上报用户,不许劣质充数)
```

1. **生成**:按 manifest 的 ID 和规格生成。工具预算内优先(PixelLab 等免费额度);要花钱先请示(报工具、价格、预计用量)。生成记录(ID、工具、提示词、日期、重试次数)写入 manifest。
2. **质检**:跑 `tools/评分器/`(见下节)。达标线在立项卡定。
3. **入库**:素材文件进 `assets/art/`(按类别分目录,文件名=资产 ID),manifest 状态改"已入库"。
4. **回归**:该资产参与的玩法流程重跑(引擎操作手册),确认尺寸/锚点/遮挡/动画没被换坏。

## 评分器规范(确定性,可执行——规范写成代码)

三个检查器,输入输出固定,AI 只消费结论:

| 检查器 | 输入 | 输出 | 默认口径 |
|---|---|---|---|
| `调色板一致性` | 资产图 + 参考图(立项卡指定) | 每图主色与参考色板的 Lab 距离分,超阈清单 | 平均距离 ≤ 阈值 T(立项定,先松后紧) |
| `帧间一致性` | 帧序列目录 | 相邻帧感知哈希距离曲线 + 跳变帧清单 | 相邻帧距离 ≤ 阈值;序列尺寸/锚点一致 |
| `尺寸规格` | manifest | 不合规清单(尺寸/格式/透明度/命名) | 零容忍,必须全绿 |

评分器输出 JSON + 人类可读摘要,存 `evidence/资产质检/`。**评分器不代替游戏内回归**(评分器过≠游戏里没问题)。

## 出处与许可证(红线)

- 每件"已入库"资产必须填 manifest 的"出处"与"许可证"两列:生成=工具名+提示词日期;素材源=URL+许可证名。
- 只用明确可商用的来源;登录墙后的内容不许爬。
- 许可证禁商用的工具链同理不引入(DaxianLee/cocos-mcp-server 即因此未采用):引入任何工具前查 LICENSE,只收 MIT/Apache/可商用。
