> 判定管线成功的标准:用 001 跑出「快多少 / 省多少」的真实数据(对比手工开发基线)。

| 模块 | 内容 | 来源 | 手册落点 | 状态 |
|---|---|---|---|---|
| M1 玩法切片链路 | 需求 → 白盒 → 可玩循环 | GameFactory 方法论平移 | `手册/玩法切片.md` | ⬜ |

## 2D 资产行业现状(影响 M2 设计)

- 可用工具:PixelLab、Rosebud PixelVibe 等;起步预算走云端 API 免费额度(Meshy 注册送 100 点/月等),不需要 GPU。
- 未解难题:**帧间一致性 + 风格全局一致性**。应对:图生图精修 + 后处理 + **把质检做成确定性评分器**——这正是本管线差异化的重点,评分器优先级高于生成器。
