# 微信开放数据域 — 好友排行榜的正确实现方式(知识文档)

> 为什么单独立这份文档:好友排行榜是微信小游戏最特殊的系统,**主域代码拿不到好友关系链数据**——这是微信的隐私安全模型,不是技术难度问题。用错方式(主域硬拉好友数据)会直接无法通过审核或运行时报错。
> 状态:知识捕获(2026-09-29),未实测;接入时按当期微信官方文档核实并回填。

## 机制:两个运行上下文

微信小游戏有**两个隔离的 JS 环境**:

| | 主域(游戏本体) | 开放数据域(独立上下文) |
|---|---|---|
| 能访问好友关系链数据 | ❌ 永远不能 | ✅ `wx.getFriendCloudStorage()` / `wx.getGroupCloudStorage()` |
| 能用游戏引擎吗 | ✅ 完整引擎 | ⚠️ 受限上下文:大部分主域 API 不可用,**渲染到 sharedCanvas** |
| 互相通信 | `wx.getOpenDataContext().postMessage()` 单向发送 | `onMessage` 接收,**不能直接回传数据** |

## 数据流(组件库 leaderboard 的设计依据)

```
主域                                     开放数据域(独立工程/目录)
────                                     ──────────────────────
1. 玩家分数变化
   wx.setUserCloudStorage({KVDataList})
   (只有自己的数据可由主域写)
                                         3. 收到 postMessage("refresh")
2. 排行榜界面打开                            wx.getFriendCloudStorage()
   postMessage({type:"refresh"})   ───→      拉好友 KV 数据,排序
                                             画到 sharedCanvas(自行排版)
4. 界面上的 Sprite 贴 sharedCanvas ←──   (渲染即共享,无数据回传)
```

## 主域工程配置要点

- `game.json`(微信侧)声明 `"openDataContext": "open-data-context"`(目录名自定);
- **Cocos Creator 3.x 构建微信包**:开放数据域是**独立构建**的(单独一份构建配置产出到主包内约定目录),构建配置里主域填"开放数据域代码目录";这一步要在构建配置工具/手册里固化,不能靠记忆;
- 主域与开放数据域**不能用同一个引擎实例**:开放数据域通常用极简 Canvas 2D 手绘排行榜,不引入 Cocos;
- 包体:开放数据域代码计入**主包**,排版逻辑要克制(几 KB);
- `sharedCanvas` 尺寸由主域设置(上屏 texture),清晰度=canvas 分辨率,注意大屏模糊问题(设 2x)。

## 对组件库的接口影响(已反映在 core/contracts.ts)

- `ILeaderboard.submitScore()`:主域 `wx.setUserCloudStorage`,安全直接;
- `ILeaderboard.supportsFriendList()===true` 的平台(微信),**好友榜的"读+渲染"不经过普通组件回调**——`reddot`/`leaderboard` 组件在微信上要渲染好友榜时,走:postMessage 通知 → 开放数据域自绘 → Sprite 贴 sharedCanvas;
- 组件的 UI 绑定清单里,好友榜区域要登记为"开放数据域渲染区",引擎里放一个指定 name 的 Sprite 节点,开放数据域绘制内容自动上屏;
- 世界榜(非好友)不经开放数据域:走自建服务端或微信云开发,**当前管线裁剪强联网**,世界榜默认不做(能力边界已声明)。

## 常见坑(接入时核对)

- 开放数据域里 `wx.getSystemInfo` 等主域 API 不存在,别复制主域代码过去;
- postMessage 数据量要小(发指令不发数据集);高频 postMessage 有节流;
- 好友云存储 KV 每用户有 key 数量与频率限额(当日写入上限),分数提交别每帧调;
- 分数序列化用字符串(KVData value 只收 string),组件层统一 `String(score)`;
- 真机与开发者工具的开放数据域表现有差异,验收必须真机看好友榜。
